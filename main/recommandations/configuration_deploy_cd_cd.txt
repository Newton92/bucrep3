# Déploiement d'un projet Django sur Ubuntu 24.04 LTS

Je vais vous guider à travers les étapes pour déployer votre projet Django sur un serveur Ubuntu 24.04 avec un pipeline de déploiement automatisé depuis GitHub.

## Choix des technologies

Pour ce déploiement, je recommande :
- **Serveur web**: Nginx (plus léger et mieux adapté à Django qu'Apache)
- **Serveur d'application**: Gunicorn
- **Base de données**: PostgreSQL (mais vous pouvez garder SQLite si c'est un petit projet)
- **Environnement virtuel**: Python venv
- **Outils de déploiement**: GitHub Actions ou un simple script shell avec des hooks Git

## 1. Préparation du serveur

### Mise à jour du système
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y git python3-pip python3-venv nginx postgresql postgresql-contrib
```

### Configuration de PostgreSQL (optionnel)
```bash
sudo -u postgres psql
CREATE DATABASE yourdbname;
CREATE USER youruser WITH PASSWORD 'yourpassword';
ALTER ROLE youruser SET client_encoding TO 'utf8';
ALTER ROLE youruser SET default_transaction_isolation TO 'read committed';
ALTER ROLE youruser SET timezone TO 'UTC';
GRANT ALL PRIVILEGES ON DATABASE yourdbname TO youruser;
\q
```

## 2. Configuration de l'environnement

### Création d'un utilisateur pour l'application
```bash
sudo adduser --system --group django
sudo usermod -aG sudo django
sudo su - django
```

### Configuration du répertoire du projet
```bash
mkdir -p ~/app/{src,venv,logs}
cd ~/app/src
git clone https://github.com/votreutilisateur/votreprojet.git .
```

### Création de l'environnement virtuel
```bash
python3 -m venv ~/app/venv
source ~/app/venv/bin/activate
pip install -r requirements.txt
```

## 3. Configuration de Gunicorn

### Installation
```bash
pip install gunicorn
```

### Création du fichier de service systemd
`/etc/systemd/system/gunicorn.service`
```ini
[Unit]
Description=gunicorn daemon
After=network.target

[Service]
User=django
Group=django
WorkingDirectory=/home/django/app/src
ExecStart=/home/django/app/venv/bin/gunicorn --access-logfile - --workers 3 --bind unix:/home/django/app/src/app.sock votreprojet.wsgi:application

[Install]
WantedBy=multi-user.target
```

### Activation du service
```bash
sudo systemctl start gunicorn
sudo systemctl enable gunicorn
```

## 4. Configuration de Nginx

### Création du fichier de configuration
`/etc/nginx/sites-available/yourdomain`
```nginx
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    location = /favicon.ico { access_log off; log_not_found off; }
    location /static/ {
        root /home/django/app/src;
    }

    location /media/ {
        root /home/django/app/src;
    }

    location / {
        include proxy_params;
        proxy_pass http://unix:/home/django/app/src/app.sock;
    }
}
```

### Activation du site
```bash
sudo ln -s /etc/nginx/sites-available/yourdomain /etc/nginx/sites-enabled
sudo nginx -t
sudo systemctl restart nginx
```

## 5. Pipeline de déploiement automatisé

### Option 1: Script de déploiement avec hook Git (simple)

Créez un script `~/app/deploy.sh`:
```bash
#!/bin/bash

echo "Début du déploiement"
cd /home/django/app/src

# Pull les dernières modifications
git pull origin main

# Active l'environnement virtuel
source /home/django/app/venv/bin/activate

# Installe les dépendances
pip install -r requirements.txt

# Effectue les migrations
python manage.py migrate --noinput

# Collecte les fichiers statiques
python manage.py collectstatic --noinput

# Redémarre Gunicorn
sudo systemctl restart gunicorn

echo "Déploiement terminé"
```

Rendez-le exécutable:
```bash
chmod +x ~/app/deploy.sh
```

### Option 2: GitHub Actions (plus avancé)

Créez un fichier `.github/workflows/deploy.yml` dans votre repo:
```yaml
name: Deploy Django App

on:
  push:
    branches: [ main ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
    - name: SSH into server and deploy
      uses: appleboy/ssh-action@master
      with:
        host: ${{ secrets.SSH_HOST }}
        username: ${{ secrets.SSH_USERNAME }}
        key: ${{ secrets.SSH_KEY }}
        script: |
          cd /home/django/app/src
          git pull origin main
          source /home/django/app/venv/bin/activate
          pip install -r requirements.txt
          python manage.py migrate --noinput
          python manage.py collectstatic --noinput
          sudo systemctl restart gunicorn
```

## 6. Sécurité

### Configuration du firewall
```bash
sudo ufw allow 'Nginx Full'
sudo ufw enable
```

### Configuration de Django
- Assurez-vous que `DEBUG=False` en production
- Configurez `ALLOWED_HOSTS` avec votre domaine
- Utilisez HTTPS avec Let's Encrypt

### Installation de Certbot pour HTTPS
```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
```

## 7. Surveillance et maintenance

### Journalisation
Configurez la rotation des logs dans `/etc/logrotate.d/django`:
```
/home/django/app/logs/*.log {
    weekly
    missingok
    rotate 12
    compress
    delaycompress
    notifempty
    create 640 django django
    sharedscripts
    postrotate
        systemctl restart gunicorn
    endscript
}
```

### Surveillance des ressources
Installez `htop` pour surveiller les ressources:
```bash
sudo apt install htop
```

## Conclusion

Vous avez maintenant une configuration complète pour:
1. Un serveur Django avec Gunicorn et Nginx
2. Une base de données PostgreSQL (optionnel)
3. Un pipeline de déploiement automatisé via GitHub ou un script local
4. Une configuration sécurisée avec HTTPS

Pour déployer des mises à jour, il suffira de pousser sur votre branche main (si vous utilisez GitHub Actions) ou d'exécuter manuellement le script `deploy.sh`.
