### **🚀 Ajouter des Notifications en Temps Réel avec Django Channels**

Django Channels permet d'envoyer des notifications instantanées sans recharger la page, grâce aux WebSockets. Voici comment l'intégrer dans ton projet.

---

## **🛠 1️⃣ Installer Django Channels**
Exécute cette commande pour installer Django Channels :

```sh
pip install channels channels-redis
```

Ajoute `channels` à `INSTALLED_APPS` dans `settings.py` :

```python
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'channels',  # Ajout de Django Channels
    'ton_app',   # Remplace par le nom de ton application
]
```

---

## **⚙ 2️⃣ Configurer Channels dans `settings.py`**
On configure **Redis** comme backend pour gérer les connexions WebSockets.

```python
ASGI_APPLICATION = "config.asgi.application"

# Utilisation de Redis comme broker pour les WebSockets
CHANNEL_LAYERS = {
    "default": {
        "BACKEND": "channels.layers.InMemoryChannelLayer",  # Pour du local
        # Pour un environnement de production avec Redis, utilise :
        # "BACKEND": "channels_redis.core.RedisChannelLayer",
        # "CONFIG": {
        #     "hosts": [("127.0.0.1", 6379)],  # Assure-toi que Redis est installé et en marche
        # },
    },
}
```

---

## **📡 3️⃣ Créer un Routeur pour WebSockets (`routing.py`)**
Dans le dossier de ton projet (`config/` ou `ton_app/`), crée un fichier `routing.py` :

```python
from django.urls import re_path
from .consumers import NotificationConsumer

websocket_urlpatterns = [
    re_path(r"ws/notifications/$", NotificationConsumer.as_asgi()),
]
```

Dans `asgi.py`, importe et ajoute `ProtocolTypeRouter` :

```python
import os
from django.core.asgi import get_asgi_application
from channels.routing import ProtocolTypeRouter, URLRouter
from channels.auth import AuthMiddlewareStack
from ton_app.routing import websocket_urlpatterns

os.environ.setdefault("DJANGO_SETTINGS_MODULE", "config.settings")

application = ProtocolTypeRouter({
    "http": get_asgi_application(),
    "websocket": AuthMiddlewareStack(
        URLRouter(websocket_urlpatterns)
    ),
})
```

---

## **🖥 4️⃣ Créer un Consumer WebSocket (`consumers.py`)**
Crée un fichier `consumers.py` dans ton application et ajoute :

```python
import json
from channels.generic.websocket import AsyncWebsocketConsumer

class NotificationConsumer(AsyncWebsocketConsumer):
    async def connect(self):
        self.user = self.scope["user"]
        if self.user.is_authenticated:
            self.group_name = f"user_{self.user.id}"
            await self.channel_layer.group_add(self.group_name, self.channel_name)
            await self.accept()
        else:
            await self.close()

    async def disconnect(self, close_code):
        if self.user.is_authenticated:
            await self.channel_layer.group_discard(self.group_name, self.channel_name)

    async def receive(self, text_data):
        pass  # On ne reçoit pas de messages des utilisateurs ici

    async def send_notification(self, event):
        await self.send(text_data=json.dumps({
            "message": event["message"],
            "type": event["type"],
            "commande": event.get("commande", None),
        }))
```

## **🔄 5️⃣ Envoyer une Notification via WebSockets**
Dans les signaux (`signals.py`), ajoute l'envoi de notifications WebSockets en plus de l'enregistrement en base de données.

```python
from asgiref.sync import async_to_sync
from channels.layers import get_channel_layer
from django.db.models.signals import post_save
from django.dispatch import receiver
from .models import Notification

def send_ws_notification(user, type_notif, message, commande=None):
    """Envoie une notification en temps réel via WebSockets."""
    channel_layer = get_channel_layer()
    async_to_sync(channel_layer.group_send)(
        f"user_{user.id}",
        {
            "type": "send_notification",
            "message": message,
            "type": type_notif,
            "commande": commande.notre_ref if commande else None,
        }
    )

@receiver(post_save, sender=Notification)
def notifier_utilisateur(sender, instance, created, **kwargs):
    """Quand une notification est créée, on l'envoie aussi en temps réel."""
    if created:
        send_ws_notification(instance.user, instance.type, instance.message, instance.commande)
```

## **🌍 6️⃣ Intégration côté Frontend (Vue.js ou JavaScript Vanilla)**

Ajoute ce script dans ton frontend pour écouter les notifications en temps réel :

```javascript
const socket = new WebSocket("ws://localhost:8000/ws/notifications/");

socket.onmessage = function (event) {
    const data = JSON.parse(event.data);
    alert(`🔔 Nouvelle notification : ${data.message}`);
};

socket.onclose = function () {
    console.log("WebSocket fermé, reconnexion dans 5 secondes...");
    setTimeout(() => location.reload(), 5000);
};
```

Si tu utilises Vue.js, tu peux stocker les notifications dans **Vuex** ou **Pinia** et les afficher dans une barre de notifications.

## **🚀 Test et Déploiement**
### **📌 Lancer Django Channels**
Django Channels remplace `runserver`, donc utilise :

```sh
python manage.py runserver
```

Si tu veux utiliser Redis en production :

```sh
docker run -d -p 6379:6379 redis
```

Puis dans `settings.py` :

```python
CHANNEL_LAYERS = {
    "default": {
        "BACKEND": "channels_redis.core.RedisChannelLayer",
        "CONFIG": {
            "hosts": [("127.0.0.1", 6379)],
        },
    },
}
```
