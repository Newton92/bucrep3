Importations Géographiques

Gestion des données géographiques

Information importante

Ces commandes permettent de peupler les provinces pour chaque pays, puis d'associer les villes existantes à leurs provinces respectives.

Il est recommandé d'exécuter d'abord "Import Provinces", puis "Associer Villes".
Import Provinces

Importe les provinces pour tous les pays actifs du système.

Associer Villes

Associe chaque ville existante à sa province correspondante.

Import Complet

Exécute les deux étapes (provinces + villes) en séquence.
