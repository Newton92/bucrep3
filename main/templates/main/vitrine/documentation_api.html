Endpoints / Acheteurs
POST

/acheteur/add

Soumettre un nouvel acheteur pour traitement par les services du BUCREP. Cet endpoint permet l'enregistrement d'un acheteur.

Paramètres de la requête

user_id

string • requis

Identifiant unique de l'utilisateur. Doit correspondre à la norme ISO 3166-2:CM.

Exemple: "CM-CE"

agent_token

uuid • requis

Token d'identification de l'agent recenseur généré lors de la session active.

payload

object • requis

Objet JSON contenant les données de recensement (membres du foyer, conditions de vie).

Réponses attendues

200 Succès - Données enregistrées
400 Erreur - Payload mal formé
401 Non autorisé - Token invalide

Documentation technique (BUCREP). © 2026

Exemple de requête

// POST /data/collecte 
{
    "region_id": "CM-CE",
    "agent_token": "a8f3-4d5e-92c1",
    "timestamp": "2023-11-15T10:30:00Z",
    "payload": {
        "foyer_id": 12903,
        "membres": 5,
        "localisation": {
            "lat": 3.848,
            "long": 11.502
        }
    }
}

{
    "status": "success",

    "message": "Données reçues"
